# YUVO Internship – Data Analysis Project

## Overview

This project contains my 4-week YUVO Internship tasks based on the **World Bank Fertility Rate dataset (1960–2011)**.

The main purpose of this project was to understand the complete data analysis process using R, starting from data cleaning and ending with statistical analysis, predictive modeling, and final reporting.

## Dataset

- Dataset: World Bank Fertility Rate
- Time Period: 1960–2011
- Main Variable: Fertility Rate
- Tools: R, RStudio and GitHub

---

# Week 1 – Data Cleaning

In Week 1, I worked on cleaning and preparing the fertility rate dataset for analysis.

### Work Done

- Checked the structure of the dataset.
- Handled missing values.
- Checked data quality and consistency.
- Identified possible outliers.
- Prepared a cleaned dataset.
- Used R for data cleaning and processing.

### Outcome

A clean and organized dataset was prepared for visualization and further analysis.

---

# Week 2 – Data Visualization

In Week 2, I created different visualizations using **R and ggplot2** to understand patterns in the data.

### Visualizations Created

- Line Chart
- Bar Chart
- Scatter Plot
- Histogram
- Boxplot

### Key Insights

- Fertility rates show an overall decreasing trend over the years.
- Fertility rates are different across countries.
- The distribution of fertility rates shows considerable variation.
- The visualizations make the dataset easier to understand and communicate.

---

# Week 3 – Statistical Analysis and Predictive Modeling

In Week 3, I performed statistical analysis and built a predictive model using R.

### Work Done

- Calculated descriptive statistics.
- Performed correlation analysis.
- Created a statistical hypothesis.
- Divided the data into training and testing sets.
- Built a Linear Regression model.
- Evaluated the model using:
  - R²
  - RMSE
  - MAE
- Performed 5-fold cross-validation.
- Created model diagnostic plots.
- Checked residuals and model performance.
- Compared the linear model with a quadratic model.

### Key Findings

- Year has a negative relationship with fertility rate.
- The relationship is statistically significant.
- Year alone explains only part of the variation in fertility rates.
- Additional variables could improve the predictive model.

---

# Week 4 – Comprehensive Data Analysis Report

In Week 4, I combined the work from the previous three weeks into one complete analysis report.

### Work Done

- Combined data cleaning results.
- Included data visualizations.
- Included statistical analysis and predictive modeling results.
- Explained important findings and insights.
- Documented challenges and lessons learned.
- Added possible future improvements.
- Prepared a final comprehensive report.

### Outcome

A complete data analysis project was created from the original dataset to the final report.

---

# Overall Key Findings

- Fertility rates generally decreased from 1960 to 2011.
- There are significant differences in fertility rates between countries.
- Year has a negative relationship with fertility rate.
- Statistical analysis supports the presence of a relationship between Year and Fertility Rate.
- A single variable such as Year is not enough to accurately explain all fertility-rate variation.
- Additional demographic, economic, and country-level variables could improve future analysis.
